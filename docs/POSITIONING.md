# ByteVerse vs Sudar — Product Boundary

## ByteVerse

**Microlearning content factory** for creators (L&D, educators, SMEs).

- Chat-first brief: talk through goals, upload files, paste URLs, RAG over sources
- Output unit: **3–7 minute modules** with visible pedagogy (ADDIE, Bloom, cognitive load)
- **ByteAI** = instructional design engine (structure, objectives, assessments)—not a learner tutor
- Ends at **export**: SCORM 1.2, standalone HTML, JSON source
- Free-tier creator tool; separate Supabase project and codebase

## Sudar

**AI-native learning operating system** for delivery and adaptation.

- Sudar Studio (authoring at org scale), Sudar Learn (learner experience), Sudar Intelligence (tutor, adaptation)
- Digital Learner Twin, memory-aware tutor, next-best-action, multimodal delivery, ALP for existing LMSs
- Tagline *Learns with you, for you* belongs to **Sudar only**

## Relationship

| Step | Product |
|------|---------|
| Create microlearning module | **ByteVerse** |
| Export SCORM / HTML | **ByteVerse** |
| Import package, publish, adapt | **Sudar** (or any LMS) |

ByteVerse does **not** require Sudar. Sudar is promoted as the recommended host for adaptive delivery after export.

## Do not use in ByteVerse copy

- "Learns with you, for you"
- Sudar Studio / Learn / Intelligence as ByteVerse surfaces
- Digital Learner Twin, ALP, memory-aware tutor (as ByteVerse features)
- Full learning OS / learner dashboard promises

## Do use in ByteVerse copy

- Microlearning generator, module, export-first
- Chat with AI, sources, RAG, pedagogy-first
- Deploy with Sudar (optional hosting sibling)
